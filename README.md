# dotfiles

For Towelbro !!
Linux only. `$HOME` is the git repo (whitelist `.gitignore`).

## Includes

- [nvim](https://github.com/neovim/neovim) ([LazyVim](https://www.lazyvim.org/))
- [starship](https://starship.rs/)
- [herdr](https://herdr.dev/)
- [lazygit](https://github.com/jesseduffield/lazygit)
- [uv](https://github.com/astral-sh/uv)
- git, build-essential, ripgrep, fd-find (via apt)

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/towelbro0812/dotfiles/main/install.sh | bash
```
